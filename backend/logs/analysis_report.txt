10. LIMITATIONS  [READ BEFORE CITING ANY NUMBER]
--------------------------------------------------------------------------------
1. Single session, single subject.
   All metrics are from one ~71-second session with one participant. Results
   cannot be generalized to a population or cited as system accuracy.

2. Autocorrelation / effective sample size.
   Rows are logged at ~13.5 fps. Consecutive frames are highly autocorrelated.
   The effective statistical n is the number of labeled segments: 4
   (2 normal segments, 1 drowsy segment, 1 distracted segment), NOT the 782 labeled rows.
   No valid confidence intervals can be computed from this data alone.

3. Labeling delay, direction unknown.
   Latency is measured from the first row carrying the new ground-truth label, set by a
   human keypress. The offset between keypress and true onset was NOT measured and its sign
   is unknown (key before behavior overstates latency; key after understates it).
   Treat latency as indicative only; it is NOT an upper bound.

4. Average latency is over n=2 segments.
   The average detection latency is the mean of exactly 2 measurements (one drowsy,
   one distracted). It is not a statistically stable estimate.

5. Kinematic channel is simulated.
   The kinematic (steering/accelerometer) modality uses synthetic data in this log.
   trigger_reason='KINEMATIC' rows do not reflect real vehicle sensor events.

6. No labeled row reached High Risk or Critical Risk (max CSI over the whole
   log = 64); upper zones were not exercised.

7. Recovery-state hysteresis inflates Evaluation B recall.
   INTERVENING persists after the zone drops back below threshold. This means Eval B
   correctly labels frames that Eval A misses, but this is partially due to system state
   memory rather than the signal being truly at-risk at that moment.

8. Evaluation B was defined after Evaluation A's results were seen
   (post hoc, exploratory), not pre-registered.

9. Eval A and Eval B latencies are identical because the first at-risk
   row in both is the same zone crossing; B's latency is not independent evidence.
